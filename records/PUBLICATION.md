# Public edition

This repository is a sanitized public edition of the NumPy GPT Lab project. It was created with a new Git root, rather than making the old private history public. The complete original private backup is preserved separately.

Included: current project source, research checkpoints, synthetic exercises, prepared standard-library corpus with its notices, relative-path source catalogs, technical documentation and sanitized historical source snapshots.

Excluded: private Git history and original archive ZIPs, user screenshots, local capture/recovery scripts, original absolute-path manifests, private experiment run metadata, and local Python environments/caches.

Historical source snapshots are therefore not represented as exact byte-for-byte private releases. Source catalogs now identify Python files relative to the standard library. The active corpus-preparation code also emits relative source paths so newly generated catalogs remain portable.

The project MIT license applies to original project material; third-party corpus notices remain in effect. This publication does not establish debugging reliability, secure behavioral execution, exact pipeline resume or a working checker-and-retry system. The technical guide distinguishes implemented features from proposals.

The public tags public-v1-source, public-v2-source and public-v3-source identify sanitized historical snapshots. public-initial identifies the complete initial public edition. These are publication snapshots, not recovered original development commit timestamps.
